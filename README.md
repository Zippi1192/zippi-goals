# 2026 GOALS v0.4.0

個人用ローカルファーストPWA。GitHub Pagesにはアプリ本体だけを置き、記録データはiPhoneのIndexedDBに保存します。

## v0.4の主な変更
- TODAYを自動保存化し、「今年あと少し」「動かしたい」を優先表示
- GOALSを「あと少し / 継続・挑戦中 / 達成済み」に整理
- 漫画・ゲーム・映画・アニメ・ボドゲ等に「一覧を見る」を追加
- カレンダー初期表示を現在月に修正し、「今月」ボタンと過去月の月次集計サマリーを追加
- ＋追加を「最近・よく使う」順に改善
- 月末レポートを整理し、Storyを「SNSハイライト版 / 20目標フル版」の2種類に対応
- 「公表済みにする」で目標⑳へ自動反映
- 設定画面の開発用語を詳細欄へ整理

## 更新
GitHub Pages上の公開ファイルをこのフォルダの中身で上書きし、PWAの「設定 → 更新を確認」から更新してください。DBはv4のままで、既存データを維持します。
